# Catálogo de Filmes em Java

Programa de console para gerenciar um catálogo de filmes, feito em Java como projeto de estudo e portfólio.

## O que o programa faz

- Lista os filmes do catálogo
- Adiciona novos filmes (título, ano e nota)
- Busca filmes por parte do título
- Filtra filmes por nota mínima
- Salva os filmes no arquivo `filmes.txt` ao sair e carrega ao iniciar
- Valida a digitação: se for digitada uma letra onde se espera um número, o programa avisa e pergunta de novo

## Exemplo de uso

```
=== Menu ===
1 - Listar filmes
2 - Adicionar filme
3 - Buscar por titulo
4 - Listar por nota minima
0 - Sair
```

## Tecnologias

- Java (JDK 27)
- IntelliJ IDEA
- Git e GitHub

## Como rodar

1. Instale o JDK e o IntelliJ IDEA
2. Clone o repositório: `git clone https://github.com/luishgalvao98-ai/catalogo-filmes-java.git`
3. Abra a pasta do projeto no IntelliJ
4. Execute a classe `Main`
