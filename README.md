# Catálogo de Filmes em Java

Projeto de portfólio para praticar Java e orientação a objetos.

## O que o programa faz

- Guarda filmes com título, ano e nota
- Mostra o catálogo na tela

## Tecnologias

- Java
- IntelliJ IDEA
- Git e GitHub

## Como rodar

1. Instale o JDK (Java)
2. Baixe este repositório
3. Abra a pasta `src` e execute o arquivo `Main.java`
